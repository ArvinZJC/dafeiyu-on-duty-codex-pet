# Character and artwork credits

Dafeiyu On Duty adapts the community-created DeepSeek character **大肥鱼** (Dafeiyu, “Big Fat Fish”), also known as **鲸鱼娘** (Whale Girl). It is an unofficial fan project and is not endorsed by DeepSeek or OpenAI.

- Original character **溟月**: [上善无形](https://space.bilibili.com/4456176).
- DeepSeek maid Whale Girl design: [ZipZipPipe](https://space.bilibili.com/4168597).
- Reference artwork and animations: [PC2005-cloud/dsh-pet](https://github.com/PC2005-cloud/dsh-pet), inspected at commit `e821ddccdef5dd24c2663c163e0b62d15b0646a5`.
- Visual references: `dsh-pet/assets/preview/daiji-huxi-xiuxian.gif` and `dsh-pet/assets/pic/notify-done.png` in that repository.

Adaptation work uses AI-assisted image generation and manual sprite editing to preserve the reference design in the ChatGPT pet format. The adaptation adds nine animation states and sixteen gaze poses, with transparent cells, resized artwork and animation previews.
